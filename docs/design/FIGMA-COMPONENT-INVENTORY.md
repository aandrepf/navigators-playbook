### 1.2. Diagnóstico Real de Acesso: Sessão Autenticada vs. Dev Mode vs. API REST vs. Licença Pro

Com o login concluído no navegador do Orca (`page 3f9d6b92-ff35-49a0-92db-23c61ffb11cf`), verificamos empiricamente o que cada canal libera ou bloqueia:

1. **Design Mode Autenticado + Painel `Variables` (`&view=variables`) + Runtime `window.figma` (`100% ACESSÍVEL E EXPORTADO`)**:
   - Com a conta autenticada e o arquivo aberto em `Drafts` (plano `Free`), o botão **`Variables` (`ref=e13`)** na barra lateral esquerda abre a tabela completa das 3 coleções (`Tailwind 528 variables`, `Style 553 variables`, `Mode 78 variables`).
   - Mais importante: o objeto global **`window.figma`** fica ativo no contexto da página, permitindo executar `await figma.loadAllPagesAsync()`, `figma.variables.getLocalVariableCollections()`, `figma.variables.getLocalVariables()`, `figma.getLocalTextStyles()`, `figma.getLocalEffectStyles()`, `figma.getLocalGridStyles()` e inspecionar `componentPropertyDefinitions` de todos os `COMPONENT_SET`s e `COMPONENT`s do arquivo.
   - **Nota sobre modos da coleção `Style` no plano Figma Free**: na interface visual da tabela `&view=variables`, a 7ª coluna de modo exibe `"Upgrade to access more modes"` para edição manual porque o plano gratuito do Figma limita a edição de múltiplos modos na UI; porém, via `window.figma.variables.getLocalVariables()`, **todos os 8 modos (`Nova`, `Vega`, `Maia`, `Lyra`, `Mira`, `Luma`, `Sera`, `Rhea`)** são lidos integralmente sem restrição.

2. **Dev Mode (`&m=dev` / `radio "Dev Mode" ref=e2337`) (`BLOQUEADO PELO PLANO FIGMA FREE — EXIGE PLANO PROFESSIONAL`)**:
   - Ao acionar o seletor `Dev Mode` (`ref=e2337`) ou navegar para `?node-id=7050-2702&m=dev`, o Figma carrega brevemente o inspetor lateral (`Layer properties`, abas `List`/`Code`, `Language: CSS`) mas imediatamente sobrepõe o modal bloqueante **`dialog "Upgrade to work in Dev Mode" (ref=e2588)`** com os botões `"Upgrade to Professional"` e `"Back to Design Mode"`.
   - **Conclusão técnica**: o Dev Mode não depende apenas de login; exige assinatura paga **Figma Professional / Organization / Enterprise** na conta logada. Essa limitação foi 100% contornada pela extração direta via `window.figma` no Design Mode combinada com os artefatos TSX oficiais do registro `shadcncraft.com/r/radix-vega/*.json`.

3. **API REST Externa do Figma (`GET https://api.figma.com/v1/files/bl5eJw33wjuSWJwGZ3KUnl/...`) (`EXIGE X-FIGMA-TOKEN`)**:
   - Chamadas HTTP externas para `api.figma.com/v1` não usam o cookie de navegador do `www.figma.com`; exigem cabeçalho `X-Figma-Token: figd_...` (Personal Access Token gerado em *Figma Settings → Security → Personal access tokens* com escopo `file_content:read`). Sem esse token, retorna `HTTP 403 {"status":403,"err":"Invalid token"}`. Além disso, o endpoint REST `/v1/files/:key/variables/local` é restrito a contas **Figma Enterprise**.
   - Portanto, a extração via `window.figma` na sessão autenticada do navegador é **mais completa** do que a própria API REST pública, pois entrega todas as 1.159 variáveis mesmo em conta Figma gratuita.

4. **Itens Pro do Catálogo `shadcncraft` (`EXIGEM LICENÇA COMERCIAL SHADCNCRAFT`)**:
   - Na página `Pro` (`10335:4860`), os quadros `400+ more blocks in Pro` (`10354:8693`), `Sales & Marketing Dashboard` (`10354:8778`), `HR Dashboard` (`10354:8800`), `ClearFlow` (`10354:8818`), `Banking` (`10354:8825`) e `AI Chat` (`10354:8843`) contêm **capturas de tela estáticas (`RECTANGLE` com imagem)** demonstrando os pacotes pagos (`Pro Figma $299` / `Pro React $249`).
   - No endpoint de registro (`https://shadcncraft.com/r/radix-vega/<item>.json`), os **22 itens gratuitos** retornam `HTTP 200` com o código TSX completo, enquanto os **352 blocos Pro e 58 componentes Pro** retornam `HTTP 401 Unauthorized` sem `SHADCNCRAFT_LICENSE_KEY`, embora seus metadados (`name`, `type`, `title`, `description`, `dependencies`, `registryDependencies`, `categories`) estejam 100% públicos em `registry.json` (`HTTP 200`).
