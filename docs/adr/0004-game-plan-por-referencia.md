# Game plan referencia jogadas em vez de copiá-las

O game plan de um jogo é uma lista ordenada de referências a jogadas do playbook, com notas específicas daquele confronto, e não uma cópia da jogada no contexto do jogo. Escolhemos referência para manter uma fonte única de verdade: corrigir uma atribuição no playbook reflete em todos os game plans que a usam. O custo aceito é que não existe "versão da jogada daquele jogo" — ajustes pontuais vão nas notas do game plan.
