# Jogada estruturada agora, editor de desenho depois

O valor imediato está em distribuir e consultar jogadas, não em desenhá-las. Cada jogada nasce como dados estruturados (nome, unidade, formação, situação, atribuição por posição) com imagem opcional anexada, e o editor de campo fica fora do MVP. A alternativa — construir um editor à altura do Playmaker antes de validar a distribuição — foi rejeitada por transformar o MVP num produto dentro do produto. Consequência: o modelo de rota e posição é desenhado desde já para receber o editor sem migração destrutiva.
