# 17: Game plan

**What to build:** O staff monta o plano do confronto escolhendo jogadas do playbook, ordenando e anotando cada uma. O jogador vê o game plan do próximo jogo, e uma edição na jogada reflete no plano sem duplicar conteúdo.

**Blocked by:** 07 (Playbook — jogada com atribuições), 16 (Jogo e disponibilidade)

**Status:** ready-for-agent

- [ ] Staff adiciona jogadas visíveis a ele ao game plan de um jogo
- [ ] Staff ordena as jogadas do game plan e escreve uma nota por jogada
- [ ] Editar a jogada no playbook reflete no game plan, sem cópia divergente
- [ ] Jogador vê o game plan do próximo jogo, respeitando a visibilidade de cada jogada
- [ ] Jogada arquivada continua no game plan, marcada como arquivada, e não é oferecida em novas seleções
- [ ] Testes de ordenação e de visibilidade no game plan
